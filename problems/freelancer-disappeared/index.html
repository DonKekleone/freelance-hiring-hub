Freelance Project Problems

The freelancer disappeared. Protect the project before chasing the person.

When communication stops, your first job is to preserve access, document the current state and determine what work actually exists.

Secure anything you already control

Confirm access to domains, hosting, repositories, design files, cloud storage and shared accounts. Do this before changing anything that could accidentally destroy useful work.

Document the project state

What has actually been delivered?
What has already been paid?
What deadlines were agreed?
What communications show the current scope?
Which files or accounts are still missing?
Can another freelancer continue from the existing work?

Send one clear status request

Avoid sending ten emotional messages. Ask for a specific response by a reasonable deadline and state exactly what information or files you need.

Separate recovery from replacement

You may ultimately need another freelancer. First determine whether the existing work is usable and what access must be recovered.

The replacement hire should not inherit the same structural problem.If account control, documentation or milestones were weak the first time, fix those conditions before restarting.

Review the payment or platform process

If the project used a marketplace, escrow system or payment provider, review the current dispute and recovery options before deadlines expire.
