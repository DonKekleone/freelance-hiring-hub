Freelance Hiring Template

A project handoff checklist for ending the job without loose ends.

Final delivery should include the files, access, documentation and ownership details needed to use the work after the freelancer leaves.

Final deliverables

Final approved files received.
Editable or source files received where included.
Correct export formats delivered.
Documentation received.
Outstanding revisions completed.

Accounts and access

Repository access confirmed.
Hosting access confirmed.
Domain control confirmed.
Shared passwords rotated where appropriate.
Temporary freelancer access removed when no longer needed.

Ownership and licensing

Ownership transfer completed where required.
Third-party licenses documented.
Stock assets identified.
Fonts and software dependencies documented.
Portfolio-use expectations understood.
Completion is more than receiving the final image, file or website.The buyer should be able to operate, edit or maintain the asset according to the agreed scope.

Close cleanly

Confirm final payment, archive project communications and preserve useful documentation for future work.
