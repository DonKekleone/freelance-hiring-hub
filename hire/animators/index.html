Hire an animator around the motion, style and production requirements.

Animation projects vary widely in technique, complexity and production time. Define the format and visual direction before comparing quotes.

Define the animation type

2D animation.
3D animation.
Character animation.
Explainer animation.
Logo animation.

Frame-by-frame work.

Provide timing and references

Length alone does not determine workload. Style, number of scenes, character complexity and revision depth also matter.

Clarify production responsibilities

Determine who handles storyboard, illustration, voiceover, sound and final editing.

Ten seconds of animation can contain a large amount of production work.Evaluate complexity, not runtime alone.

Define delivery formats

Specify resolution, aspect ratio, transparency, editable project files and any platform-specific exports.
