Hire Freelancers

Hire an SEO specialist for a defined search problem.

SEO can involve technical work, content strategy, research, implementation and measurement. Avoid hiring against a vague promise to 'rank the site.'

Define what kind of SEO help you need

Technical audit.
Keyword research.
Content planning.
On-page optimization.
Site architecture.
Local search.
Reporting.
Implementation support.

Ask how the work will be measured

Useful metrics depend on the project. Rankings can matter, but traffic quality, conversions, indexing and technical improvements may also be relevant.

Avoid certainty theater

Search engines involve variables no freelancer fully controls. Strong candidates should be able to explain a process without promising guaranteed positions.

A useful SEO proposal says what work will be performed.A vague monthly retainer is difficult to evaluate even when the price sounds attractive.

Understand who implements recommendations

An audit has limited value if nobody owns the technical and content changes that follow.
