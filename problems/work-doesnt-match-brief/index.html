Freelance Project Problems

The work does not match the brief. First determine whether the brief actually said what you think it said.

Quality disputes become easier to resolve when both sides can point to written requirements instead of reconstructing expectations from memory.

Compare the work to explicit requirements

Separate requirements that were actually documented from preferences that were never communicated.

Identify the type of mismatch

A required deliverable is missing.
A technical requirement was ignored.
The creative direction differs from the reference.
The quality level is below relevant portfolio examples.
The buyer changed expectations after kickoff.
The brief contains contradictory instructions.

Give actionable feedback

Describe the gap between the agreed requirement and the delivered work. Avoid feedback that only says the result feels wrong.

A written brief gives disagreement somewhere to land.Without one, both sides can sincerely remember the project differently.

Update scope when the target changes

If the buyer now wants something materially different, treat that as a scope change rather than disguising it as a correction.
